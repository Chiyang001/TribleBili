# 哔哩哔哩批量三连工具

一个基于 Flask 的 Web 应用，支持批量对哔哩哔哩视频进行点赞、投币、收藏操作。

## 功能特性

- ✅ 批量视频链接三连
- ✅ 对指定用户的所有视频一键三连
- ✅ 自定义操作（单独点赞/投币/收藏）
- ✅ 投币数量可选（1币或2币）
- ✅ 收藏夹可选
- ✅ 实时操作反馈

## 安装步骤

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 运行应用：
```bash
python app.py
```

3. 打开浏览器访问：
```
http://localhost:5000
```

## 使用说明

### 1. 获取登录信息

在哔哩哔哩网站登录后，按 F12 打开开发者工具：
- 进入 Application（应用程序）标签
- 左侧选择 Cookies → https://www.bilibili.com
- 找到并复制以下三个值：
  - `SESSDATA`
  - `bili_jct`
  - `buvid3`

### 2. 登录应用

在网页中填入上述三个值，点击"登录"按钮。

### 3. 设置操作

选择要执行的操作：
- 点赞
- 投币（可选择1币或2币）
- 收藏（需选择收藏夹）

### 4. 批量处理视频

**方式一：批量视频链接**
- 在文本框中输入视频链接，每行一个
- 支持格式：
  - 完整链接：`https://www.bilibili.com/video/BV1xx411c7XD`
  - BV号：`BV1xx411c7XD`
  - 短链接：`https://b23.tv/xxxxx`

**方式二：用户视频三连**
- 输入UP主的空间链接：`https://space.bilibili.com/123456`
- 点击"获取用户视频"
- 点击"对所有视频三连"
